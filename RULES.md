# Hackathon rules

## Event

**Devin Hacks Kochi**

**Dates:** 24–25 October 2026 (overnight)

**Location:** Kochi, Kerala. The exact venue is in the organizers' announcement; the public event page lists it as "Venue TBC".

**Website:** [devinhacks.in](https://www.devinhacks.in/)

**Registration:** [Luma event page](https://luma.com/3v8n74l1)

**Hosts:** Vaishakh Suresh, Viswanatha Kartha V and Alen Biju (Devin Community Kochi)

All times below are in **Indian Standard Time (IST, UTC+05:30)**:

- Start: **24 October, 5:00 PM**
- Code freeze: **25 October, 8:00 AM** (as announced by the organizers at the venue)
- Wrap-up: **25 October, by 11:00 AM**

## Participation and building

1. **Solo hackathon.** You participate as an individual, with no team.
2. **The theme is open.** Bring an idea and build something you wish existed.
3. **Start from scratch at the event.** Libraries, APIs and public datasets are welcome. Pre-built projects are not allowed.
4. **Build with Devin.** The event is about AI-assisted software development with Devin. Keep a short, accurate record of how AI tools were used in [AI_USAGE.md](AI_USAGE.md).
5. **Submit your code repository, a short project description and a working demo**, following the organizers' submission instructions. [SUBMISSION.md](SUBMISSION.md) collects these items.

## Source and repository guidance

These rules summarise the public [event website](https://www.devinhacks.in/), the [Luma page](https://luma.com/3v8n74l1), and announcements made at the venue. Organizer instructions always take precedence over this file.

This repository started from an older community-hackathon template, which the organizers later said is optional. Its documentation files have been updated for Devin Hacks Kochi. [AGENTS.md](AGENTS.md) adds project workflow conventions; they are not event eligibility rules.
